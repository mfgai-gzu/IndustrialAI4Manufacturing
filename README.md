# IndustrialAI4Manufacturing

> Industrial AI Projects for Smart Manufacturing

An open-source engineering project integrating mold design, computer vision, and artificial intelligence for intelligent manufacturing.

---

## 📌 Project Vision

IndustrialAI4Manufacturing aims to bridge traditional manufacturing engineering with modern AI technologies.

This project focuses on applying Artificial Intelligence, Computer Vision, and Data Analysis to real-world manufacturing scenarios, including mold design, quality inspection, defect detection, and intelligent production.
