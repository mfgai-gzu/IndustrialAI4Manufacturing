# 冲压模具设计项目：四角形弯曲件三合一复合模

## 项目概述

本项目完成了一款四角形弯曲件的冲孔-落料-弯曲三合一正装复合模设计。该零件为电子电器、五金构件中常见的连接与支撑件，材料为10钢冷轧薄板（厚度1.2mm），外形尺寸38mm×42mm，折弯高度24mm，中心有φ8mm定位孔，折弯角度要求90°±0.5°。

## 技术方案

| 项目 | 内容 |
|------|------|
| 零件材料 | 10钢冷轧薄板，t=1.2mm |
| 工艺路线 | 冲孔 → 落料 → 校正弯曲 |
| 模具类型 | 三合一正装复合模 |
| 排样方式 | 单排有废料直排 |
| 材料利用率 | 88.56% |
| 最大冲裁力 | 96.87 kN |
| 模具闭合高度 | 211.2 mm |
| 压力机选型 | J23-25开式可倾压力机（250 kN） |

## 设计亮点

1. **三级不等高凸模时序控制**：通过冲孔凸模、落料凸模、弯曲凸模的天然高度差，实现“压料→冲孔→落料→校正弯曲”的工序时序分离
2. **双向回弹控制**：上模弹性卸料+下模弹性顶料双向校正结构，在下死点对弯曲区域施加强制整形压力，抵消10钢回弹（2.5°~4°），确保90°±0.5°折弯精度
3. **集成化设计**：单次冲程产出完整成品，相比单工序模效率提升2倍以上
