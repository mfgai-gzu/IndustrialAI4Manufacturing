# 注塑模具设计项目：EPP发泡玩具盖壳体两板模

## 项目概述

本项目完成了一款EPP（发泡聚丙烯）玩具盖壳体的注塑模具设计。塑件为中空多边防护壳体，采用EPP发泡材料，密度极低（0.09g/cm³），单件质量仅0.33g，具有高韧性、高回弹、抗冲击、防震缓冲特性。模具采用一模两腔单分型面两板式结构。

## 技术方案

| 项目 | 内容 |
|------|------|
| 零件材料 | EPP发泡聚丙烯 |
| 成型收缩率 | 2.0% |
| 模具类型 | 一模两腔单分型面两板模 |
| 模架规格 | CI型大水口标准模架（2327-A70-B80-C80） |
| 模具外形 | 280mm × 270mm × 281mm |
| 浇口类型 | 侧浇口（厚度1.2mm，宽度4mm） |
| 顶出方式 | 12根φ3mm顶杆多点分散顶出 |
| 注塑机 | XS-Z-30卧式注塑机（锁模力300kN） |
| 成型周期 | 约35-50秒 |

## 设计亮点

1. **EPP发泡材料适应性设计**：针对EPP剪切敏感特性，加宽侧浇口截面（4mm），降低熔体剪切速率，避免发泡空洞和气泡缺陷
2. **双面独立闭环冷却**：型腔+型芯双面环绕水路，左右型腔独立回路，消除温差导致的发泡倍率不一致和壳体翘曲
3. **薄壁软质塑件顶出方案**：12根φ3mm细顶杆多点均匀分布，分散顶出力，杜绝EPP发泡件顶白、凹陷、扭曲
4. **双重定位导向**：导柱导套+四角虎口定位，抵抗充模发泡过程中的侧向分力
